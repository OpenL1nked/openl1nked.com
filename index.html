Why OpenL1nked?

Everything you love about proprietary phone-desktop bridges — open, transparent, and yours to control.

Truly Cross-Platform

Desktop clients for Windows, macOS and Linux; mobile for Android, with limited iOS support planned.

Privacy-First

End-to-end encryption for every communication channel — your data stays between your own devices.

Feature-Rich

App mirroring, notification sync, file transfer, shared clipboard, full messaging and desktop control.

Mobile Data Ready

Stay linked over the internet, not just Wi-Fi, via a self-hostable relay server — still end-to-end encrypted.

Modern Tech

Rust & Tauri power a lightweight, fast and secure desktop experience with a small footprint.

Open, By You, For You

Transparent, community-driven development — MIT licensed, no ads, no telemetry, no vendor lock-in.

Proposed Technology Stack

The modern, open stack the project is being designed around.

Desktop App Tauri

Rust backend, web frontend — a fast, lightweight, secure shell.

Mobile (Android) Kotlin

Heavily inspired by & leveraging KDE Connect's architecture.

Protocol KDE Connect Protocol

End-to-end encrypted, robust and already proven across platforms.

Remote Connectivity WebSocket Relay

Custom Rust/Node.js relay server for when devices aren't on the same LAN.

App Mirroring scrcpy-inspired

High-performance screen streaming, wrapped for a native desktop feel.

Planned Roadmap

A pre-development project — every phase is a goal we're building toward together.

Phase 1

Foundation & LAN Connectivity

The bedrock of OpenL1nked: secure, local device communication.

  • Tauri desktop project structure
  • KDE Connect device discovery over UDP (Rust)
  • Pairing & TLS encryption
  • Desktop UI for devices, pairing & status
  • Foundational Android app
  • Reliable LAN connection, desktop ↔ mobile
Phase 2

Remote Connectivity via Relay

Connecting your devices, no matter where they are.

  • Secure, privacy-focused WebSocket relay server
  • Automatic LAN → relay fallback
  • Custom relay server settings
  • End-to-end encrypted relay traffic
Phase 3

Core Features & Messaging

Essential functionality and a seamless messaging experience.

  • Notification sync with reply/dismiss
  • Bidirectional shared clipboard
  • Robust file transfer UI
  • SMS/MMS conversation history & sending
  • RCS messaging via Google Messages for Web
Phase 4

High-Bandwidth & Polish

The differentiating features that make OpenL1nked truly powerful.

  • High-performance app mirroring (Android)
  • Desktop controls (lock, shutdown, etc.)
  • Full macOS & Linux clients
  • Limited iOS client
  • Documentation & CI/CD pipelines
